

# WanderBricks Flight Delay Insights

Analytics and machine learning on WanderBricks' flight travel data, built on Databricks.
The goal is to understand what drives flight delays and to anticipate them, so WanderBricks
can plan itineraries, set customer expectations, and choose carriers, routes and departure
times that keep travellers on schedule.

## Business questions

- Which airlines, airports and departure times carry the highest delay risk?
- How does delay risk change across the day, the week and the season?
- Can we flag likely-delayed flights before departure using schedule information alone?
